What This Tests

This page tests the relative path navigation between notes and canvas files. Instead of using chrome:// URLs, we're using relative paths (./note.xhtml, ./canvas.xhtml) that should work in any web context.

Technical Details

  • Relative Paths: Using ./note.xhtml and ./canvas.xhtml
